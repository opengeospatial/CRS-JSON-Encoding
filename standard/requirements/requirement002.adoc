[[req_class_name]
[requirement]
====
[%metadata]
identifier:: /req/core/name
part:: Primary names (excluding aliases) shall be an object conform to the https://TODO/mdj.json#MD_Identifier[ISO 19115-4 MD_Identifier schema].
====

The following fragment is equivalent to `MD_Identifier` schema:

[source,json]
----
{
  "$anchor": "MD_Identifier",
  "type": "object",
  "properties": {
    "authority": {
      "$ref": "#CI_Citation"
    },
    "code": {
      "type": "string"
    },
    "codeSpace": {
      "type": "string"
    },
    "version": {
      "type": "string"
    },
    "description": {
      "type": "string"
    }
  },
  "required": [
    "code"
  ]
}
----
